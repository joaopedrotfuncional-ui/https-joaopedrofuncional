# JP Sports — GitHub Pages + WhatsApp

Versão estática para GitHub Pages. **Não utiliza Supabase, Google Sheets ou Google Apps Script.**

## Publicação
Envie o conteúdo desta pasta diretamente para a raiz do repositório publicado pelo GitHub Pages. O arquivo `index.html` deve ficar na raiz selecionada em **Settings → Pages**.

## Inscrições
O formulário registra uma cópia local no navegador e abre o WhatsApp da JP Sports com os dados preenchidos. O participante precisa confirmar o envio da mensagem no WhatsApp.

## Área administrativa
A área ADM permite criar uma senha local, consultar registros salvos naquele navegador e exportar CSV.

## Limitação
Sem um banco de dados/servidor, os registros dos celulares dos participantes não são sincronizados com o navegador do administrador. Não use este painel local como lista centralizada de inscrições.
