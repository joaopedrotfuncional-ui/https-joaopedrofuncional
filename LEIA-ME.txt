JP SPORTS — GITHUB PAGES + WHATSAPP + PAINEL ADM LOCAL

IMPORTANTE: ESTA VERSAO NAO USA SUPABASE, GOOGLE SHEETS OU GOOGLE APPS SCRIPT.
Nao precisa criar config.js nem colar URL de nenhum servico.

COMO ATUALIZAR NO GITHUB PAGES
1. Extraia este ZIP.
2. Abra a pasta extraida.
3. Envie TODOS os arquivos que estao diretamente dentro dela para a raiz do repositorio (onde fica o index.html).
4. Substitua os arquivos antigos quando o GitHub perguntar.
5. Faca Commit changes e aguarde o GitHub Pages publicar.
6. Abra o site e atualize com Ctrl+Shift+R (Windows) ou Cmd+Shift+R (Mac).

INSCRICOES
O formulario salva uma copia local no navegador em que foi preenchido e abre o WhatsApp JP Sports (+55 81 99951-0223) com a mensagem pronta. O participante precisa tocar em ENVIAR no WhatsApp.

PAINEL ADM
Clique em Area ADM. No primeiro acesso naquele navegador, crie uma senha de pelo menos 8 caracteres. O painel mostra somente solicitacoes salvas naquele mesmo navegador/dispositivo e permite exportar CSV.

LIMITACAO IMPORTANTE
Sem banco de dados ou servidor, os registros feitos nos celulares dos participantes NAO aparecem automaticamente no computador do administrador. A senha e os dados do painel ficam apenas no armazenamento local daquele navegador. Limpar os dados do navegador pode apagar os registros.
