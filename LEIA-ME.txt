JP SPORTS — GITHUB PAGES + WHATSAPP + PAINEL LOCAL

PUBLICAÇÃO
1. Extraia o ZIP.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório GitHub.
3. Settings > Pages > Deploy from a branch > main > /(root).

INSCRIÇÃO
O participante preenche os dados, o site salva uma cópia local no navegador e abre o WhatsApp +55 81 99951-0223 com a mensagem pronta. O participante ainda precisa tocar em ENVIAR no WhatsApp.

PAINEL ADM
Clique em Área ADM. No primeiro acesso naquele navegador, crie uma senha de pelo menos 8 caracteres. O painel mostra apenas as solicitações salvas naquele mesmo navegador/dispositivo. Permite marcar pagamento e exportar CSV.

ATENÇÃO — LIMITAÇÃO SEM BANCO DE DADOS
Esta versão NÃO sincroniza inscrições entre dispositivos. Os dados ficam no armazenamento local do navegador que preencheu o formulário. Portanto, inscrições feitas pelos celulares dos participantes NÃO aparecerão automaticamente no computador do administrador. Limpar dados do navegador pode apagar os registros. A senha também protege apenas o painel local, não substitui autenticação de servidor.
